# コインパーキング料金・最大料金の税込・税抜スマート計算機

駐車時間の長さと時間単価、最大料金の有無を入力するだけで、税込・税抜の正しい駐車料金を瞬時に正確算出するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/parking-coin-tax-calculator/）。
2. 画面の指示に従って操作します。
